Veille — RGPD

Page de veille orientée développement web (SLAM) : suivre les évolutions RGPD et les traduire en décisions techniques (cookies, sécurité, droits).

Résumé & objectif

Le RGPD encadre les traitements de données personnelles : il impose une logique de minimisation, de transparence et de sécurité, avec preuve de conformité (accountability).

Ici je centralise : sources, thèmes, mini-checklists et “fiches lecture” de contenus (CNIL/EDPB/jurisprudence) + impacts concrets sur un projet web.

  • Cookies
  • Consentement
  • Droits
  • Sécurité
  • Sous-traitants
  • Transferts UE

Entrée en application

25 mai 2018

Référence : RGPD (UE) 2016/679

Objectif principal

Protéger les personnes

Données : identité, contact, IP, identifiants, etc.

Approche

Accountability

Les essentiels

Principes clés

  • Finalité définie + information claire
  • Minimisation & conservation limitée
  • Sécurité (CIA) + confidentialité
  • Traçabilité et preuve (accountability)

Droits des personnes

  • Accès / rectification
  • Effacement / opposition
  • Portabilité (export)
  • Limitation du traitement

Traduction technique (SLAM)

  • Formulaires : finalité + champs minimum
  • Cookies : scripts conditionnels + preuve de choix
  • Logs : limiter, purger, protéger l’accès
  • Sécurité : RBAC, hash MDP, CSRF/XSS
  • Exports : CSV/JSON (portabilité)
  • Suppression : anonymisation/purge
